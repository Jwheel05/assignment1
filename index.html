Labs 4 & 5: Interactive Data Visualization with D3.js

Text to introduce the dataset and how to use the interface, including at least one insight from the dataset:

This dataset consists of 8145 array entries of continents (Items) from years 1960 to 2015. Each of the following countries represents an item and the the following are it's attributes: Continent, income, year, gdp, lifeexpectancy, and childdeaths. To use the visualization, the slider at the top will represent the year that is being shown in the data. The dropdowns allow the user to select the different axis and data attributes the user wants to see. The user can hover over any bubble within the visualization and get the name of the country and continent. An insight from the dataset is that typically for a country that has a higher income, they tend to have less childdeaths as well as a higher life expentancy.
