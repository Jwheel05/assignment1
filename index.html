PROJECT INFORMATION

About This Visualization

Dataset: CMSC471's Daily Weather in the U.S., 2017, sourced from NOAA GHCN. States and actual station names come directly from the original file, including Puerto Rico and Guam.

Design: Two station-specific temperature lines and grouped precipitation/snowfall bars allow users to compare weather patterns across different locations. State and station dropdowns filter the observations, while interactive tooltips provide additional details about each measurement.

Interactions: Users can switch between daily maximum, minimum, and average temperatures. They can also compare precipitation and snowfall totals. Brushing the temperature graph selects a date range and updates the precipitation graph accordingly.

Data Handling: Temperature measurements use Fahrenheit, while precipitation and snowfall use inches. Daily average temperature is calculated using minimum and maximum temperatures. Precipitation and snowfall are summed over the selected period. Missing values are excluded from calculations.
